# Roadmap

The initial release candidate is a source distribution for local or trusted
deployments. The [validation guide](VALIDATION.md) records the tested scope.

Before a supported binary distribution:

- Complete an external deployment review and establish a private reporting channel.
- Automate builds with checksums, signatures, provenance and an SBOM.
- Define supported platforms, backends and version compatibility.

Broader model and accelerator validation, multi-worker lifecycle configuration
and a public Go API remain future work.
